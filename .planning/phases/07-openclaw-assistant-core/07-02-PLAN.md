  <action>
    Create a new backend module `packages/backend/src/modules/assistant/` following the existing module pattern.

    **assistant.schema.ts:** Define Zod schemas:
    - `chatRequestSchema`: `{ message: z.string().min(1).max(10000), sessionKey: z.string().min(1) }` for the chat request body
    - `resetResponseSchema`: `{ data: { sessionKey: z.string() } }` for the session reset response

    **assistant.routes.ts:** Create a Fastify plugin with 2 endpoints:

    1. `POST /chat` -- SSE streaming proxy to OpenClaw:
       - Auth: `app.authenticate` hook (JWT or API key)
       - Receives `{ message, sessionKey }` from the request body
       - Calls OpenClaw Gateway `POST ${config.OPENCLAW_GATEWAY_URL}/v1/chat/completions` with:
         - `Authorization: Bearer ${config.OPENCLAW_GATEWAY_TOKEN}`
         - Body: `{ model: "openclaw:main", messages: [{ role: "user", content: message }], stream: true, user: sessionKey }`
       - If OpenClaw returns non-2xx, respond with 502 and `{ error: { code: "OPENCLAW_ERROR", message } }`
       - On success, stream the SSE response directly to the client:
         - Set response headers: `Content-Type: text/event-stream`, `Cache-Control: no-cache`, `Connection: keep-alive`, `X-Accel-Buffering: no`
         - Use `reply.raw.writeHead()` and `reply.raw.write()` to pipe the ReadableStream from OpenClaw to the client
         - Use `reply.raw.end()` in a finally block to close the connection
         - Set a generous timeout (120s) on the request to handle long assistant responses with tool calls
       - IMPORTANT: Use `reply.hijack()` before writing raw headers to prevent Fastify from trying to serialize the response

    2. `POST /chat/reset` -- Generate a new session key:
       - Auth: `app.authenticate` hook
       - Returns `{ data: { sessionKey: "dashboard:<timestamp>" } }` with a new unique session key
       - This is called when Ines clicks "New conversation"

    **assistant.test.ts:** Basic tests:
    - Test that chat endpoint requires authentication (401 without token)
    - Test that reset endpoint returns a new session key
    - Test that chat endpoint returns 502 when OpenClaw is unreachable (mock fetch to reject)

    **app.ts:** Register the assistant routes with `prefix: '/api/v1/assistant'`. Import `assistantRoutes` and add `app.register(assistantRoutes, { prefix: '/api/v1/assistant' })` alongside the other route registrations.
  </action>

  </verify>
