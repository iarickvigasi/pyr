## Draft Generation

When generating a reply draft for a guest conversation:

1. Use the conversations skill to load full context
2. Apply the brand voice from SOUL.md -- warm, personal, mindful
3. Detect the language of the guest's message and reply in the same language (EN or DE)
4. Flag edge cases (complaints, medical, dietary, cancellations, adoption inquiries) as "sensitive -- review carefully"
5. Keep the reply concise and personal -- never corporate
6. Always sign off as Ines
7. Never commit to pricing without availability data, never give medical advice, never promise specific puppies
